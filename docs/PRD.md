# PRD — 카페 메뉴판 (Excel 구동)

## 1. 배경과 목적

매장 점주는 개발자가 아니다. 메뉴 가격·품절·디자인을 바꿀 때마다 코드를 고치게 할 수 없다. 점주가 이미 쓰는 도구인 Excel로 메뉴판 화면을 직접 관리하게 한다.

이 프로젝트는 강의 앵커 예제이기도 하다. "데이터(Excel)와 표현(템플릿)을 분리한다"는 원칙을 한 화면에서 보여준다.

## 2. 사용자

| 사용자 | 하는 일 | 기술 수준 |
|---|---|---|
| 점주 | Excel에서 메뉴·가격·품절·테마를 수정하고 저장 | Excel만 사용 |
| 손님 | 매장 화면(태블릿·모바일·사이니지)에서 메뉴를 본다 | 읽기 전용 |
| 개발자(수강생) | 테마 CSS 추가, 코드 확장 | 웹 기초 |

## 3. 목표 / 비목표

**목표**
- Excel 저장 후 사용자 조작 없이 화면이 갱신된다.
- 코드 수정 없이 Excel만으로 메뉴·매장명·테마·자동전환을 바꾼다.
- 테마 추가는 CSS 파일 추가만으로 끝난다.

**비목표 (v1)**
- 화면에서 메뉴 편집, 로그인, 주문·결제.
- 다중 매장, 이미지 업로드, 다국어.
- WebSocket 양방향 통신.

## 4. 기능 요구사항

각 항목은 `plan.md`의 테스트 항목으로 쪼갠다. ID는 테스트 이름에 붙인다.

### F1. 메뉴 시트 → 페이지

- F1-1. 시트 이름이 `_`로 시작하지 않으면 페이지 1개로 변환한다. 시트 이름이 페이지(탭) 이름이다.
- F1-2. 첫 행은 헤더다. 열: `메뉴명`, `가격`, `설명`, `품절`, `카테고리`.
- F1-3. 시트를 추가하면 페이지가 자동으로 늘어난다.
- F1-4. 시트 순서가 탭 순서다.

### F2. 데이터 규칙

- F2-1. `가격`은 숫자만 허용한다. 화면에서 `원`을 붙이고 천 단위 구분자를 표시한다. (예: `4500` → `4,500원`)
- F2-2. `품절`이 `Y`면 취소선 + 흐림 + "품절" 라벨로 표시한다. 빈칸이면 판매 중이다.
- F2-3. `카테고리`가 있으면 한 페이지 안에서 소제목 그룹으로 나눈다. 없으면 그룹 없이 나열한다.
- F2-4. 메뉴명이 빈 행은 무시한다.
- F2-5. 가격이 숫자가 아니면 해당 행을 건너뛰고 서버 로그에 시트명·행 번호를 남긴다. 서버는 죽지 않는다.

### F3. `_설정` 시트

| 항목 | 값 | 기본값 |
|---|---|---|
| 매장명 | 문자열 | `메뉴판` |
| 테마 | `cafe-dark` \| `bistro-light` | `cafe-dark` |
| 자동전환초 | 0 이상 정수 | `0` |

- F3-1. 매장명을 화면 제목에 표시한다.
- F3-2. 테마 값에 맞는 CSS를 적용한다. 알 수 없는 값은 기본 테마로 대체한다.
- F3-3. `자동전환초`가 0이면 수동 전환, 양수면 그 초마다 다음 페이지로 순환한다.
- F3-4. `_설정` 시트가 없거나 항목이 비어 있으면 기본값을 쓴다.

### F4. 실시간 갱신

- F4-1. Excel 저장 시 서버가 파일 변경을 감지한다. 짧은 시간의 중복 이벤트는 300ms 디바운스로 한 번에 합친다.
- F4-2. 서버가 재파싱 후 SSE `menu-updated` 이벤트를 푸시한다.
- F4-3. 브라우저가 이벤트를 받으면 `GET /api/menu`로 새 데이터를 받아 재렌더링한다. 새로고침이 필요 없다.
- F4-4. 현재 보고 있던 페이지(탭)를 갱신 후에도 유지한다. 해당 시트가 사라졌으면 첫 페이지로 이동한다.
- F4-5. 파싱에 실패하면(파일 잠금·손상) 이전 정상 데이터를 유지하고 오류를 로그에 남긴다.
- F4-6. SSE 연결이 끊기면 브라우저가 자동 재연결한다.

### F5. 화면

- F5-1. 탭으로 페이지를 전환한다.
- F5-2. 디바이스별 반응형: 모바일, 태블릿 세로, 태블릿 가로, 사이니지. (`design/` 참조)
- F5-3. 사이니지·키오스크용으로 브라우저 전체화면에서 `자동전환초` 순환이 동작한다.
- F5-4. 시각 규칙은 `.claude/rules/anti-ai-slop.md`를 따른다.

## 5. 테마

- v1 필수: `cafe-dark`(어두운 카페, 앰버), `bistro-light`(밝은 비스트로, 브릭레드).
- 디자인 핸드오프에는 `beige`, `cream`, `deep-green`, `forest-dark`, `forest-light`, `light-olive`도 있다. v1 이후 확장 후보다. 새 테마는 CSS 추가 + 허용 값 목록 갱신만으로 가능해야 한다.

## 6. 성공 기준

- 점주가 Excel을 저장하고 **2초 이내**에 화면이 갱신된다.
- 코드를 한 줄도 바꾸지 않고 메뉴·가격·품절·테마를 변경할 수 있다.
- 잘못된 Excel 입력(가격 문자, 빈 시트)으로 서버가 중단되지 않는다.
- 파서와 렌더링 로직의 단위 테스트가 모두 통과한다.

## 7. 제약과 위험

- 로컬 `.xlsx`는 **저장(Ctrl+S) 시점에만** 디스크에 기록된다. 저장 전에는 반영되지 않는다. OneDrive 자동저장이면 즉시 반영된다. 점주 안내 문서에 명시한다.
- Excel이 파일을 열고 있는 동안 잠금·임시 파일(`~$menu.xlsx`)이 생긴다. 감시 대상은 `data/menu.xlsx` 하나로 제한한다.
- 보안 스캐너가 SheetJS에 오탐을 낼 수 있다. 공식적으로 무시 권장이다.

## 8. 확장 아이디어 (범위 밖)

- 테마 CSS 추가 (같은 데이터, CSS만 교체).
- 사내 파일서버의 `menu.xlsx`를 ETag 폴링으로 갱신.
- 키오스크 전체화면 순환.
